# Projeto 5 — Feature de front construída com agente

**Módulo 05 · semana 15 · ≈ 10h**

## Objetivo
Construir uma feature real de interface usando agentes de codificação, com processo registrado, e
avaliar honestamente o ganho.

## Escopo
- Feature integrada a um sistema seu (ex.: busca semântica no painel, assistente de dúvida na tela
  de operação)
- Construída majoritariamente via agente, com registro dos prompts e das correções necessárias
- Chamada de IA **no servidor**, com rate limit por usuário
- Teste E2E agentivo do fluxo principal
- Acessibilidade verificada: teclado, contraste, leitor de tela no fluxo principal

## Critérios de aceite
- [ ] Feature no ar e usada por alguém de verdade
- [ ] Registro do processo: prompts, iterações, o que precisou refazer
- [ ] Nenhuma chave de API no cliente (com teste ou revisão provando)
- [ ] Rate limit por usuário funcionando
- [ ] Teste E2E agentivo passando
- [ ] Acessibilidade checada
- [ ] **Retrospectiva honesta**: tempo real gasto vs tempo estimado sem IA

## O aprendizado real
A retrospectiva é o entregável mais valioso. Muita gente afirma que IA acelerou 10x sem ter medido.
Meça o seu caso e tenha o número — em entrevista, isso te separa imediatamente.
