## Padrão de entrega

Todo projeto tem, sem exceção:

- Repositório próprio ou pasta dedicada, com README que explica o quê, por quê e como rodar
- Variáveis de ambiente documentadas em `.env.example` — **e nenhum segredo commitado**
- Testes do caminho principal
- Seção "Limitações conhecidas" no README — projeto sem limitação declarada é projeto não testado
- Medição: custo, latência e qualidade, quando aplicável

## Os três que viram portfólio

Se o tempo apertar, **não comprima estes**: projeto 3 (MCP), projeto 4 (agente autônomo) e o
capstone. São os que quase ninguém tem.
